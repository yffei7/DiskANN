search uses the same two-tier scoring as `pq_flash_index.cpp`: PQ distances for frontier neighbor pruning, full-precision for expanded candidates. This eliminates the fairness concern where in-place would do more expensive full-precision distance calls during BFS. The PQ codes are loaded from the same pre-built disk index used by the merge baseline, ensuring identical quantization.\n\n2. **Alignment safety (v5)**: Slot offsets within a page are NOT guaranteed 32-byte aligned (8-byte page header + variable bitmap → arbitrary offsets). All coord data is copied to `InPlaceSearchScratch::aligned_coord_scratch` (posix_memalign 32-byte aligned) before any SIMD distance call. This matches `pq_flash_index.cpp:1203` `node_fp_coords_copy` pattern. The copy cost is negligible relative to the distance computation.\n\n3. **Deferred reverse edges (v5)**: Reverse-edge insertions are defer-only (`DeferredEdgeBuffer::push`), drained by the maintenance thread and at each checkpoint. This matches `GraphDelta::inter_insert` semantics (graph_delta.cpp:43-60) where reverse edges accumulate in a delta and are merged later. Benefits: (a) no page writes during the insert hot path (only the forward edge write), (b) batch drain enables page-sorted I/O for locality, (c) simpler concurrency (no write-write conflicts on target pages during concurrent inserts).\n\n4. **Atomic counters for all metrics**: `std::atomic<uint64_t>` with `fetch_add` for counts. For `double` accumulators (time), use `std::atomic<double>` with a CAS loop. No mutex needed on the hot path. Per-thread latency vectors are thread-local; aggregation happens only at checkpoint.\n\n5. **Pre-built disk index for merge baseline**: User provides `--disk_index_prefix` pointing to an already-built DiskANN disk index. This avoids expensive index build at experiment start and matches real-world usage. The same PQ tables from the disk index are also loaded by the in-place backend for PQ parity.\n\n6. **Update fraction semantics**: `--update_fraction 0.05` means 5% of base_npts updates total. Split 50/50 between inserts and deletes. Update threads simply execute their share as fast as possible (no throttling). The experiment runs for `--duration_sec` and checkpoints at `--checkpoint_interval` update boundaries.\n\n7. **No modifications to existing DiskANN code**: Zero lines changed in PQFlashIndex, MergeInsert, Index, StreamingMerger, or any other existing file. graph_ann_ops.cpp reimplements graph operations using pin/unpin + PQ from the InPlaceGraphStore. MergeInsert is used as-is with external timing wrappers.\n\n---\n\n## Metric Collection Completeness Checklist\n\n| Requested Metric | InPlace Source | Merge Source | Location verified
